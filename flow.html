LINE診察券　受付・会計・翌朝でやること

毎日の入力は「電カル番号（初回のみ）」と「施術内容（自費のみ）」の2つだけです。

作成：2026-09-24 大石 牛込内科・糖尿病クリニック 様

受付 来院時

  1. 一声かける「LINEの診察券をお持ちの方は、こちらのQRの読み取りをお願いします」
  2. 受付画面に来院が表示されるチャイムが鳴ります。表示されない方は、そのまま通常の受付で構いません。
  3. 初めての方だけ：電カルの患者番号を入力受付画面のその方の行（氏名・生年月日が出ています）に入力。2回目からは不要です。
  4. 診察券をまだ持っていない方には案内同じQRから友だち追加と診察券の発行ができます。

会計 診察後

  1. 一声かける「お会計までの間に、LINEの診察券からアンケートをお願いします。次回使えるクーポンをお渡しします」
  2. クーポンを使う方：画面を見て割引患者さまが「使用する」を押した画面（使用済み・時刻入り）を確認するだけ。スタッフの操作はありません。
  3. 自費のご来院：実施した施術を選んで保存受付画面のその方の行で、メニューから選ぶだけ（1〜2タップ）。翌朝にまとめて入れても構いません。
  4. 施術後フォローが自動で始まる保存した時点で予約されます。配信ツールでの操作は不要です。
保険のご来院受付画面の操作はありません。急性・慢性のフォローは、これまで通り配信ツール側で行います。

翌朝 施術をまとめて入れる場合

  1. 受付画面の「昨日の自費のご来院」を開く前日に来院の記録があり、施術が未登録の方が並びます。
  2. 一人ずつ、実施した施術を選んで保存会計時に入力済みの方は表示されません。
  3. 保存した方から、施術後フォローの1通目がその朝に届く以降の3日後・14日後・30日後・60日後は自動です。
会計時に入力する運用の場合翌朝の作業はありません。どちらの運用にするかは、リハーサルのときに決めていただけます。

やらなくていいこと

患者さまのスマホの画面を読み取る不要
暗証番号の入力不要
フォロー配信のシナリオを別に起動する不要
QRの紙の差し替え（同じ紙をずっと使えます）不要

困ったとき

QRが読めない、LINEを使っていない → その日は通常受付。お名前か診察券番号で、受付画面から来院を手動登録できます受付
施術を間違えて保存した → 当日中は受付画面から修正できます会計
クーポンを押し間違えた → 当日中は受付画面から取り消せます会計
来院の記録が付かない → 一度LINEを閉じてQRを読み直す。それでも付かなければ手動登録受付
